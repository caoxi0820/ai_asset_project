## 你接下来怎么用

### 如果你要让另一台电脑上的 ChatGPT/Codex 自动部署
按下面顺序操作：
1. 先把对应方案的 **部署蓝图** 发给它。
2. 再把其中的 **“可直接喂给 ChatGPT/Codex 的部署指令”** 原文贴给它。
3. 如果对方机器提示需要你补充 API Key、Token、券商信息或目录路径，你人工补一下即可。
4. 部署完后，再把对应的 **使用说明** 发给未来的使用者，或者你自己照着用。

### 如果你要先选方案
- 想先便宜跑起来：优先看 **低成本** 版。
- 想要更强的数据质量、更多因子/基本面/专业接口：优先看 **高成本** 版。
- 主要看中国公募基金 / QDII：看前两套。
- 主要看美股：看后两套。

## 统一说明
- 这 4 套方案都支持你直接告诉 AI 你的持仓，例如：
  - `我持有 5000 份 161725，成本价 1.423，当前浮亏 320 元`
  - `我持有 120 股 AAPL，成本价 182.4 美元，当前浮盈 950 美元`
- 不要求你提供完整加仓减仓流水。
- 系统的核心工作流都是：
  1. 解析你的持仓；
  2. 补齐基金/股票基础信息；
  3. 拉取市场数据、估值/持仓/行业暴露/回撤/财务等数据；
  4. 做组合层综合分析；
  5. 输出一份结构化报告。

## 交付目标
这些文件的目标不是“介绍概念”，而是让另一台机器上的 ChatGPT/Codex：
- 尽量自动安装依赖；
- 尽量自动配置 MCP / skills / 工作目录；
- 在你少量人工参与的情况下完成部署；
- 最终可直接拿来分析你的持仓并生成报告。
