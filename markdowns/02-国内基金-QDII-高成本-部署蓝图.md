# 方案 2：国内基金 / QDII / 高成本部署蓝图

## 1. 方案定位
这套方案适合：
- 你不仅要看 **中国公募基金 / QDII**，还要更重视数据覆盖和专业分析深度；
- 你愿意为更稳定的数据接口投入一定成本；
- 你希望在免费工具基础上再叠加更专业的分析能力。

## 2. 组件组成（简单解释每个工具做什么）

### A. `AKShare`
作用：
- 免费底层数据补充层。
- 当高质量接口某些字段不方便取时，可作为兜底。

### B. `tushare` / `tushare-mcp-server`
作用：
- 更专业的国内金融数据接口。
- 适合补充更规范的数据访问方式、基金基础资料、部分市场指标与扩展数据。
- 在这个方案里，它是 **更稳定的数据主引擎之一**。

### C. `FundSeeker`
作用：
- 基金研究辅助层。
- 负责把基金数据做成更接近“研究报告”的分析结构。

### D. `Qlib`（可选增强）
作用：
- 偏量化研究与特征工程。
- 如果你未来想做基金组合风格漂移分析、择时/风格暴露建模、横向比较，它会非常有用。
- 这部分更偏“增强分析引擎”，不是首发必需，但高成本版建议预留。

### E. `持仓解析 + 组合报告引擎`
作用：
- 把你的自然语言持仓转结构化；
- 汇总基金数据、市场数据、组合暴露、风险提示；
- 输出可以长期复用的报告模板。

## 3. 免费 / 成本说明
- `AKShare`：免费。
- `FundSeeker`：免费。
- `Qlib`：开源免费，但部署更重。
- `tushare`：通常需要积分 / Token 体系，**不是纯免费无限制**。
- 因此这套方案属于：
  - **软件开源为主**；
  - **数据层可能有付费 / 准付费门槛**。

## 4. 为什么高成本版更强
相比低成本版，这套方案更强在：
- 数据接口更规整；
- 更容易做长期、可重复的分析流程；
- 更适合形成你自己的“基金研究工作台”；
- 更容易叠加量化风格分析、历史因子分析、同类对比分析。

## 6. 自动化部署边界

### 可以自动完成
- 环境准备；
- Python 依赖安装；
- 仓库克隆；
- 本地 skill / MCP 启动脚本生成；
- 分析入口与报告模板生成；
- 验收脚本生成。

### 需要你人工参与
- 填写 `tushare` Token；
- 决定是否启用 `Qlib`；
- 首次验证数据权限是否足够；
- 如果你要长期跑批量分析，需要确认缓存与本地存储策略。

## 7. 部署后的链路是怎么工作的
1. 你输入基金持仓和问题；
2. 持仓解析模块提取代码、份额、成本、当前盈亏；
3. `tushare` + `AKShare` 联合拉取基金数据；
4. `FundSeeker` / 自定义分析器生成基金画像；
5. `Qlib`（若启用）做风格/因子/相对对比增强；
6. 报告引擎合成输出。

## 8. 适合的报告类型
这套方案更适合输出：
- 单基金深度分析报告
- 多基金组合重合度和集中度报告
- QDII 海外风险敞口分析报告
- 月度持仓复盘报告
- 同类基金横向比较报告

## 10. 验收清单
部署完成后，至少验证：
- `tushare` Token 可正常读取（如配置）；
- `AKShare` 可用；
- 至少一个基金代码能完成全链路分析；
- 报告里有“持仓成本 / 当前盈亏 / 风险分析 / 重合度分析”；
- 当 `tushare` 不可用时，系统能自动退化到 `AKShare`。

## 11. 风险与限制
- 成本主要在数据权限而不是软件；
- 高成本版更适合长期使用，但部署更复杂；
- 若你没有 `tushare` Token，这套方案会退化成“低成本增强版”；
- 同样要保留“非投资建议”提示。
