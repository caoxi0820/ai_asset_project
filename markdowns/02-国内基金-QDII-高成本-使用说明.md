# 方案 2：国内基金 / QDII / 高成本使用说明

## 1. 适合拿来问什么
这套方案更适合以下问题：
- `这只基金和同类相比到底强在哪？`
- `我这几只基金是不是风格漂移了？`
- `我的 QDII 是否过度暴露在美股科技或者某个国家？`
- `从基金经理、历史波动、风格、资产暴露和我的成本角度，哪些持仓最脆弱？`

## 2. 你怎么提供持仓
还是直接自然语言输入即可：
```text
我当前持仓如下：
- 5000 份 161725，成本价 1.423，当前浮亏 320 元
- 3000 份 000457，成本价 1.080，当前盈利 210 元
- 2500 份 006408，成本价 1.215，当前浮亏 90 元
请帮我做一份深度持仓报告。
```

## 3. 典型用法

### 用法 A：深度分析单只基金
```text
我持有 5000 份 161725，成本价 1.423，当前浮亏 320 元。
请从以下角度给我一份深度报告：
1. 基金经理和策略稳定性
2. 历史回撤与波动
3. 行业和重仓股暴露
4. 同类产品中的相对位置
5. 我当前持仓的风险提示
```

### 用法 B：组合体检
```text
我当前持仓如下：
- 5000 份 161725，成本价 1.423，当前浮亏 320 元
- 3000 份 000457，成本价 1.080，当前盈利 210 元
- 2500 份 006408，成本价 1.215，当前浮亏 90 元

请帮我输出：
- 基金重仓和行业重合度
- 组合风格偏向
- QDII 海外暴露
- 哪些持仓的风险最大
```

### 用法 C：月度复盘
```text
这是我当前基金持仓，请给我做一份月度复盘报告，重点看：
- 组合是否更集中
- 有没有不知不觉重复押注
- 哪些基金值得重点观察
```

## 4. 系统会怎么处理你的问题
它通常按下面顺序工作：
1. 解析你的持仓；
2. 从 `tushare` 主数据源取更规范数据；
3. 用 `AKShare` 补缺；
4. 用基金分析器做基金画像；
5. 若启用了 `Qlib`，再做风格/因子增强分析；
6. 输出组合级报告。

## 5. 这套方案和低成本版的区别
你能明显感受到的区别是：
- 报告更稳定；
- 结构更“研究化”；
- 更适合做多只基金的持续追踪；
- 对 QDII 和同类基金横向比较更有帮助。

## 6. 推荐提问模板
```text
我当前持仓如下：
- [份额] 份 [基金代码]，成本价 [价格]，当前盈利/浮亏 [金额]
- [份额] 份 [基金代码]，成本价 [价格]，当前盈利/浮亏 [金额]

请输出一份深度分析报告，包含：
1. 持仓摘要
2. 单基金核心判断
3. 历史回撤与波动风险
4. 风格与行业暴露
5. 基金之间的重合度
6. QDII 海外敞口
7. 未来 1-3 个月应重点观察什么
```

## 7. 结果如何解读
建议你重点看：
- **结论摘要**：快速看整体判断；
- **风险最高持仓**：不是亏得最多，而是结构最脆弱的；
- **重合度**：这直接决定你是不是“表面分散、实际集中”；
- **QDII 暴露**：这是很多人最容易忽略的隐藏风险。

## 8. 常见问题

### Q1：没有 `tushare` Token 还能用吗？
能用，但会自动退回较弱模式。

### Q2：我没有交易记录怎么办？
不影响，这套方案只要求你告诉它当前持仓、成本和当前盈亏。

### Q3：报告能给结论吗？
能给结构化判断和观察建议，但不应被视为直接买卖指令。
