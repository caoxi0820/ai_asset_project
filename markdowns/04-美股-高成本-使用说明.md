# 方案 4：美股高成本使用说明

## 1. 适合拿来问什么
这套方案更适合你问：
- `我现在这组美股持仓，从估值、财务、波动和组合结构上看，最危险的是哪些？`
- `如果只看我当前持仓，不看交易流水，能不能做一份像投研复盘一样的报告？`
- `我的组合是不是已经过度集中在科技成长？`
- `哪些股票属于高估值但基本面支撑不足？`

## 2. 你怎么提供持仓
直接自然语言即可：
```text
我当前持仓如下：
- 120 股 AAPL，成本价 182.4 美元，当前浮盈 950 美元
- 80 股 NVDA，成本价 101.2 美元，当前浮亏 230 美元
- 60 股 MSFT，成本价 402.5 美元，当前浮盈 410 美元
请帮我做一份深度组合报告。
```

## 3. 典型用法

### 用法 A：深度组合报告
```text
我当前持仓如下：
- 120 股 AAPL，成本价 182.4 美元，当前浮盈 950 美元
- 80 股 NVDA，成本价 101.2 美元，当前浮亏 230 美元
- 60 股 MSFT，成本价 402.5 美元，当前浮盈 410 美元
- 45 股 AMZN，成本价 171.0 美元，当前浮盈 280 美元

请给我一份深度组合报告，重点看：
1. 组合集中度
2. 估值风险
3. 财务质量分层
4. 波动与回撤风险
5. 未来需要重点跟踪哪些持仓
```

### 用法 B：只筛出高风险仓位
```text
这是我的当前持仓，请直接告诉我最需要警惕的 3 个仓位，并解释原因。
```

### 用法 C：做周度复盘
```text
请根据我当前持仓做一份周度复盘模板，帮我看：
- 哪些仓位变得更集中
- 哪些仓位估值过热
- 哪些仓位虽然盈利但风险在上升
```

## 4. 系统内部会怎么工作
一般顺序如下：
1. 解析你的持仓；
2. 由高阶分析代理决定要查哪些数据；
3. MCP 工具拉取行情、估值、财务摘要、历史价格；
4. 把结果合成组合分析；
5. 输出一份研究风格更强的报告。

## 5. 报告通常长什么样
- 结论摘要
- 持仓结构概览
- 单股核心判断
- 估值与财务质量分析
- 波动与回撤风险
- 行业 / 风格集中度
- 最值得关注的仓位
- 下阶段观察清单

## 6. 推荐提问模板
```text
我当前持仓如下：
- [股数] 股 [Ticker]，成本价 [价格]，当前盈利/浮亏 [金额]
- [股数] 股 [Ticker]，成本价 [价格]，当前盈利/浮亏 [金额]

请基于我当前持仓做一份深度报告，至少包括：
1. 当前组合画像
2. 高估值风险
3. 财务质量风险
4. 波动与回撤风险
5. 组合集中度
6. 最需要警惕的仓位
7. 未来 1-4 周观察重点
```

## 7. 如何理解它给你的建议
这套方案更像“私人投研助理”，不是自动交易系统。
你要重点看：
- **高估值 + 高波动** 是否集中出现在你的核心仓位；
- **盈利仓位** 是否因为涨太多反而变成组合脆弱点；
- **亏损仓位** 是短期回撤，还是基本面和结构都在恶化；
- **组合集中度** 是否已经超出你的风险承受范围。

## 8. 常见问题

### Q1：不连券商账户能用吗？
完全可以，这套方案默认就不连券商。

### Q2：我不提供交易历史可以吗？
可以，它只按你当前持仓快照分析。

### Q3：为什么同一只股票不同天报告会不同？
因为行情、估值、波动、财务预期都在变化，这本来就是动态分析。
