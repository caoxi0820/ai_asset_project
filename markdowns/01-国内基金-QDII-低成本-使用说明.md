# 方案 1：国内基金 / QDII / 低成本使用说明

## 1. 适合拿来问什么
这套方案适合问：
- `我这只基金还能不能拿？`
- `我买的几只基金是不是重复买了同样的东西？`
- `这只 QDII 基金主要投了哪些市场和行业？`
- `我的基金组合是不是太集中在某一个赛道？`
- `按我的成本和当前盈亏来看，风险在哪里？`

## 2. 你怎么提供持仓
你只需要像聊天一样说出来：
- `我持有 5000 份 161725，成本价 1.423，当前浮亏 320 元。`
- `我持有 3000 份 000457，成本价 1.08，当前盈利 210 元。`

也可以一次说多只：
```text
我当前持仓如下：
1. 5000 份 161725，成本价 1.423，当前浮亏 320 元
2. 3000 份 000457，成本价 1.080，当前盈利 210 元
3. 2000 份 006408，成本价 1.215，当前浮亏 90 元
请帮我做组合分析。
```

## 3. 典型用法

### 用法 A：分析单只基金
```text
我持有 5000 份 161725，成本价 1.423，当前浮亏 320 元。
请从净值走势、回撤、持仓行业暴露、基金经理稳定性这几个角度帮我分析。
```

### 用法 B：分析组合是否重合
```text
我当前持仓如下：
- 5000 份 161725，成本价 1.423，当前浮亏 320 元
- 3000 份 000457，成本价 1.080，当前盈利 210 元
- 2500 份 006408，成本价 1.215，当前浮亏 90 元
请分析这些基金的重仓重合度、行业重复暴露，以及组合风险。
```

### 用法 C：专门分析 QDII 基金
```text
我持有 4000 份某只 QDII 基金，基金代码是 000834，成本价 2.03，当前盈利 160 元。
请重点分析它底层主要暴露的国家、行业和美元资产风险。
```

## 4. 背后实际发生了什么
当你发出问题后，系统会自动做这几步：
1. **解析你的持仓文字**：提取基金代码、份额、成本价、当前盈亏；
2. **查询基金资料**：基金名称、类型、基金经理、成立时间；
3. **拉取数据**：净值、回撤、区间收益、持仓、行业暴露；
4. **做组合分析**：比较你多只基金之间的重合度；
5. **生成报告**：把基金本身情况和你当前持仓状态合并输出。

## 5. 你会拿到什么样的报告
通常会包括：
- 结论摘要
- 单基金/组合基本情况
- 当前盈亏与成本位置
- 波动与回撤风险
- 持仓行业/资产暴露
- 基金之间的重复配置
- 主要风险提示
- 后续观察点

## 6. 你要避免的提问方式
尽量不要只说：
- `帮我看看这只基金`

最好补齐：
- 基金代码
- 份额
- 成本价
- 当前盈亏
- 你最想关注什么

例如：
```text
我持有 5000 份 161725，成本价 1.423，当前浮亏 320 元。
我最关心的是：继续持有风险大不大、和我现有基金是不是重合太多。
```

## 7. 常见问题

### Q1：我不提供当前盈亏行不行？
可以，但报告会少一个“持仓体感层”的维度。

### Q2：我不提供份额行不行？
可以做单基金分析，但组合权重分析会变弱。

### Q3：我不提供加仓减仓记录行不行？
可以，这套方案本来就不依赖交易流水。

## 8. 推荐提问模板
```text
我当前持仓如下：
- [份额] 份 [基金代码]，成本价 [价格]，当前盈利/浮亏 [金额]
- [份额] 份 [基金代码]，成本价 [价格]，当前盈利/浮亏 [金额]

请从以下角度输出一份报告：
1. 当前组合画像
2. 单基金风险点
3. 重仓与行业重合度
4. QDII 暴露风险（如果有）
5. 我接下来应该重点观察什么
```

## 9. 结果如何解读
- 这套方案更适合 **辅助判断**；
- 如果看到“数据缺失”或“持仓披露滞后”，这是基金公开披露节奏导致的，不一定是系统坏了；
- 结论部分重点看：
  - 组合是否过于集中；
  - 你买入成本相对当前位置是否已经处于高风险区域；
  - QDII 是否隐含你没意识到的海外行业集中暴露。
