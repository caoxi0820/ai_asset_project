# 方案 3：美股低成本部署蓝图

## 1. 方案定位
这套方案适合：
- 你主要分析 **美股个股**；
- 希望尽量少花钱；
- 想用开源工具快速搭一个能看持仓、基本面、估值、波动和组合风险的工作台；
- 可以接受免费数据源偶尔有延迟或字段变动。

## 2. 组件组成（简单解释每个工具做什么）

### A. `yfinance-mcp`
作用：
- 基于 `Yahoo Finance` 生态的数据工具层。
- 可查询美股行情、历史价格、财务摘要、估值指标、部分分析师信息。
- 在这个方案里，它是 **最低成本、最容易接进 ChatGPT/Codex 的数据入口**。

### B. `MaverickMCP`
作用：
- 面向金融研究场景的 MCP 服务方案。
- 更像一个面向 AI 的“金融工具中台”，能帮助 ChatGPT 更方便取市场数据并拼接分析链路。
- 在这个方案里，它可以作为 **统一工具入口层**。

### C. `自定义持仓解析与投研报告 skill`
作用：
- 解析你的自然语言持仓，比如：
  - `我持有 120 股 AAPL，成本价 182.4 美元，当前浮盈 950 美元`
- 自动补齐 ticker 信息；
- 结合行情、估值、财务和你的持仓状态输出报告。

### D. （可选）本地财报摘要与估值模块
作用：
- 把抓到的财务指标、估值数据、价格波动数据整理成你能读懂的结论；
- 输出你最关心的结论，例如：
  - 当前仓位是不是过于集中；
  - 哪些股票估值高但业绩支撑弱；
  - 哪些股票波动高、回撤深。

## 3. 免费 / 成本说明
- `yfinance-mcp`：通常基于免费数据链路，整体偏低成本。
- `MaverickMCP`：开源可自部署，本身不一定收费，但你要看它是否依赖其它外部数据接口。
- 持仓解析与报告 skill：本地实现，免费。
- **这套方案原则上可以做到几乎纯免费。**

## 4. 这套方案解决什么问题
- 单只美股持仓深度分析；
- 多只美股组合集中度分析；
- 行业分布、估值、波动风险分析；
- 根据你的成本价和当前盈亏做持仓诊断；
- 输出一份适合个人投资者复盘的报告。

## 6. 自动化部署边界

### 可以自动完成
- 创建目录；
- 创建虚拟环境；
- 安装 `yfinance`/MCP 依赖；
- 生成本地持仓解析与报告模块；
- 生成测试样例与报告模板。

### 需要你人工参与
- 确认是否使用 `MaverickMCP` 还是只保留 `yfinance-mcp`；
- 首次用 1~2 个 ticker 做数据可用性验证；
- 若某个开源仓库安装失败，允许 Codex 改用本地适配层。

## 7. 部署后的链路是怎么工作的
1. 你告诉 AI 你的持仓；
2. 持仓解析模块提取 ticker、股数、成本价、当前盈亏；
3. MCP 查询行情、历史价格、财务指标、估值指标、行业分类；
4. 分析层做单股分析和组合分析；
5. 报告层生成 markdown 报告。

## 8. 典型适合输出的报告
- 单只股票持仓诊断报告
- 多股票组合集中度报告
- 估值 + 波动 + 基本面联合报告
- 每周组合复盘报告

## 9. 可直接喂给 ChatGPT/Codex 的部署指令
把下面整段原样贴到另一台电脑的 ChatGPT/Codex：

```text
你现在是我的本地部署助手。请在这台电脑上为我部署一个“美股低成本分析工作台”，部署目录默认使用 ~/finance-agents/us-stock-low-cost 。

目标：
1. 使用 Python 虚拟环境部署。
2. 接入 yfinance 生态，优先接入 yfinance-mcp；如果现成 MCP 不稳定，就本地实现最小可用数据代理。
3. 可以选装 MaverickMCP；如果适合就接入作为统一工具层，否则保留 yfinance-mcp + 本地分析模块即可。
4. 创建持仓解析模块，支持如下输入：
   - 我持有 120 股 AAPL，成本价 182.4 美元，当前浮盈 950 美元
   - 我持有 80 股 NVDA，成本价 101.2 美元，当前浮亏 230 美元
5. 创建分析模块，至少支持：
   - 历史价格和回撤分析
   - 简单估值指标分析
   - 行业和持仓集中度分析
   - 组合层风险提示
6. 创建统一入口脚本，例如 `analyze_us_portfolio.py`，输入自然语言持仓和问题，输出 markdown 报告到 reports/。
7. 生成 README、env.example、示例持仓输入和示例报告。
8. 若某个开源仓库无法安装，不要停，自动实现兼容的本地替代层。
9. 部署完成后，用 AAPL 或 MSFT 做一次验收并告诉我后续怎么用。

限制：
- 不要依赖付费行情接口。
- 不要求我提供交易流水。
- 必须把我的股数、成本价、当前盈亏纳入分析。
- 报告需要同时覆盖个股视角和组合视角。

请按以下顺序执行：
A. 环境检查
B. 建目录和虚拟环境
C. 装依赖和 MCP
D. 生成持仓解析与分析脚本
E. 生成文档和示例
F. 跑一次验收
G. 告诉我以后在 ChatGPT 里怎么触发它
```

## 10. 验收清单
部署完成后至少验证：
- 能查到 `AAPL`、`MSFT` 之类的基础信息；
- 能取到历史价格；
- 能输出一份 markdown 报告；
- 报告能体现：你的成本价、股数、当前盈亏、波动/估值/组合风险。

## 11. 风险与限制
- 免费美股数据源在个别指标上不如专业终端稳定；
- 分析适合个人投资研究，不适合机构级高频或严肃交易执行；
- 建议始终输出“非投资建议”提示。
