# 方案 3：美股低成本使用说明

## 1. 适合拿来问什么
这套方案适合：
- `我这只美股现在风险大不大？`
- `我手里的股票是不是太集中在科技股了？`
- `按我的成本和当前盈亏来看，哪些仓位最危险？`
- `我的组合是成长股太多，还是估值太贵？`

## 2. 你怎么提供持仓
直接像说话一样输入：
- `我持有 120 股 AAPL，成本价 182.4 美元，当前浮盈 950 美元。`
- `我持有 80 股 NVDA，成本价 101.2 美元，当前浮亏 230 美元。`

多只一起说：
```text
我当前持仓如下：
- 120 股 AAPL，成本价 182.4 美元，当前浮盈 950 美元
- 80 股 NVDA，成本价 101.2 美元，当前浮亏 230 美元
- 60 股 MSFT，成本价 402.5 美元，当前浮盈 410 美元
请给我做组合分析。
```

## 3. 典型用法

### 用法 A：分析单只股票
```text
我持有 120 股 AAPL，成本价 182.4 美元，当前浮盈 950 美元。
请从估值、财务质量、股价回撤风险和持仓角度给我做分析。
```

### 用法 B：看组合是不是太集中
```text
我当前持仓如下：
- 120 股 AAPL，成本价 182.4 美元，当前浮盈 950 美元
- 80 股 NVDA，成本价 101.2 美元，当前浮亏 230 美元
- 60 股 MSFT，成本价 402.5 美元，当前浮盈 410 美元
- 45 股 AMZN，成本价 171.0 美元，当前浮盈 280 美元
请分析我的行业集中度、波动风险和估值风险。
```

### 用法 C：只看风险最高的仓位
```text
这是我的持仓，请帮我找出最需要警惕的 2-3 个仓位，并解释原因。
```

## 4. 背后系统怎么工作
1. 解析你的自然语言持仓；
2. 用 `yfinance-mcp` / 相关工具取行情和财务摘要；
3. 计算历史波动、回撤、估值对比；
4. 结合你的成本价和当前盈亏；
5. 输出组合报告。

## 5. 报告通常包括什么
- 结论摘要
- 持仓概览
- 个股画像
- 估值与基本面风险
- 波动与回撤分析
- 行业集中度 / 组合集中度
- 风险最高仓位
- 后续观察点

## 6. 推荐提问模板
```text
我当前持仓如下：
- [股数] 股 [Ticker]，成本价 [价格]，当前盈利/浮亏 [金额]
- [股数] 股 [Ticker]，成本价 [价格]，当前盈利/浮亏 [金额]

请输出一份美股组合分析报告，重点包括：
1. 组合集中度
2. 估值风险
3. 波动与回撤风险
4. 哪些持仓最脆弱
5. 我后续该重点盯哪些指标
```

## 7. 你怎么看结果
重点看：
- **成本位置**：你的买入点是否已经让你处在高波动区；
- **行业集中度**：如果科技权重太高，组合风险会被放大；
- **高估值 + 高波动**：这通常是最需要警惕的组合；
- **风险最高仓位**：不一定是亏最多的，而是“结构最容易出事”的。

## 8. 常见问题

### Q1：我不提供当前盈亏可以吗？
可以，但系统更难判断你当前持仓的心理压力区间。

### Q2：我只给 ticker 可以吗？
可以做市场分析，但不能做完整持仓诊断。

### Q3：我没有交易记录怎么办？
没关系，这套方案本来就是按“当前持仓快照”来分析。
