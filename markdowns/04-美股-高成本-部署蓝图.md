# 方案 4：美股高成本部署蓝图

## 1. 方案定位
这套方案适合：
- 你持有较多美股，想做更系统的研究；
- 希望同时具备：数据源、分析代理、组合报告、较强自动化能力；
- 愿意接受一定部署复杂度，或者接入部分付费/半付费数据与工具。

## 2. 组件组成（简单解释每个工具做什么）

### A. `FinRobot`
作用：
- 偏金融分析 agent 框架。
- 更适合做“研究流程编排”：抓数据、分析、摘要、对比、写报告。
- 在这个方案里，它是 **高阶分析总控层**。

### B. `MaverickMCP`
作用：
- 作为金融研究的 MCP 工具中台。
- 给 ChatGPT/Codex 一个更适合“问答式调度”的接口层。

### C. `yfinance-mcp`
作用：
- 作为美股基础行情与公开财务数据的低门槛补充。
- 高成本版里它仍然有价值，因为它能作为兜底和快速验证层。

### D. （可选）`alpaca-mcp-server` 或其它券商/账户类接口
作用：
- 如果你未来想让系统直接连接券商账户、看实时持仓或扩展成半自动化工作台，可以预留这一层。
- 但如果你只是做研究分析，不接也完全可以。

### E. `持仓解析 + 组合报告引擎`
作用：
- 统一入口；
- 解析你的自然语言持仓；
- 驱动 `FinRobot` / MCP 工具链；
- 输出标准化报告。

## 3. 免费 / 成本说明
- `FinRobot`：开源，但会带来更多依赖和运行复杂度。
- `MaverickMCP`：开源可自部署。
- `yfinance-mcp`：低成本 / 免费数据层。
- `alpaca-mcp-server`：软件层可开源，但如果你真的连接券商账户，涉及你自己的账户和使用成本。
- 因此这套方案属于：
  - **软件多数可开源自部署**；
  - **是否高成本主要看你是否叠加更强数据源和券商接口**。

## 4. 为什么它是高成本版
高成本不只是钱，也包括：
- 部署复杂度高；
- 组件更多；
- 后续维护成本更高；
- 但换来的是更强的研究流程和更像“私人投研工作台”的体验。

## 6. 自动化部署边界

### 可以自动完成
- 目录和虚拟环境；
- 仓库拉取；
- 大多数依赖安装；
- MCP 启动配置；
- 本地持仓解析与报告模块生成；
- 示例脚本和验收脚本生成。

### 需要你人工参与
- 决定是否接券商接口；
- 如果接券商，需要人工填凭证；
- 确认数据源优先级；
- 首次验收时决定用哪些 ticker 做样例。

## 7. 部署后的链路是怎么工作的
1. 你给出持仓和问题；
2. 持仓解析模块转成结构化输入；
3. `FinRobot` 作为主分析代理决定需要哪些工具；
4. `MaverickMCP` / `yfinance-mcp` 提供数据；
5. 可选券商层提供更真实的账户视角；
6. 报告引擎生成组合级研究报告。

## 8. 适合输出的报告
- 深度个股研究报告
- 持仓组合集中度与风险报告
- 估值/财务/回撤联合报告
- 周度 / 月度持仓复盘报告
- 组合观察清单报告

## 9. 可直接喂给 ChatGPT/Codex 的部署指令
把下面整段原样贴到另一台电脑的 ChatGPT/Codex：

```text
你现在是我的本地部署助手。请在这台电脑上为我部署一个“美股高成本分析工作台”，部署目录默认使用 ~/finance-agents/us-stock-high-cost 。

目标：
1. 使用 Python 虚拟环境部署。
2. 优先集成 FinRobot 作为高阶分析代理。
3. 接入 MaverickMCP 作为金融研究工具层。
4. 接入 yfinance-mcp 作为公开行情/财务数据兜底层。
5. 可选接入 alpaca-mcp-server，但只有在我明确要求时才真正配置券商账户；否则先只保留接口位和配置模板。
6. 创建持仓解析模块，支持如下输入：
   - 我持有 120 股 AAPL，成本价 182.4 美元，当前浮盈 950 美元
   - 我持有 80 股 NVDA，成本价 101.2 美元，当前浮亏 230 美元
7. 创建统一分析入口，例如 `analyze_us_portfolio.py`，至少支持：
   - 单股分析
   - 多股组合集中度分析
   - 估值/财务/回撤联合分析
   - markdown 报告输出到 reports/
8. 系统需要把“市场数据 + 我的股数 + 成本价 + 当前盈亏”统一纳入报告。
9. 生成 README、env.example、providers.yaml、broker.example.yaml、示例输入和示例报告。
10. 如果某个开源仓库装不上，不要停，自动降级成兼容的本地模块组合。
11. 部署完成后，用 AAPL 和 MSFT 做一次验收，并告诉我后续怎么在 ChatGPT Desktop 里使用。

要求：
- 默认不连接真实券商账户，除非我明确同意。
- 不要求我提供完整交易流水。
- 尽量自动完成部署，只有遇到 API key、凭证或必须确认的步骤再问我。
- 最终交付应当可长期维护、目录清晰、文档完整。

执行顺序：
A. 环境检查
B. 创建目录与虚拟环境
C. 拉取并安装 FinRobot / MCP 相关依赖
D. 生成本地持仓解析与报告模块
E. 生成配置模板与文档
F. 跑一次验收
G. 告诉我后续如何使用和扩展
```

## 10. 验收清单
部署完成后至少验证：
- `AAPL`、`MSFT` 等股票能查到行情与基础财务摘要；
- 能解析自然语言持仓；
- 能做组合层分析；
- 能输出结构化 markdown 报告；
- 若 `FinRobot` 不可用，系统能自动降级为 MCP + 本地分析模式。

## 11. 风险与限制
- 高成本版适合长期研究，但首发部署复杂；
- 若叠加券商接口，安全和凭证管理要额外注意；
- 免费数据兜底仍可能存在延迟；
- 必须保留“非投资建议”提示。
